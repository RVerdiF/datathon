POST /predict — Input esperado
{ "Fase": 3, "Gênero": "Feminino", "Ano ingresso": 2020, "Instituição de ensino": "Escola Municipal", "Pedra 20": "Quartzo", "Pedra 21": "Ágata", "Pedra 22": "Ametista", "Nº Av": 4, "IAA": 7.5, // Autoavaliação "IEG": 8.0, // Engajamento "IPS": 6.5, // Psicossocial "IDA": 7.0, // Desempenho "IPV": 5.0, // Ponto de Virada "Matem": 7.5, "Portug": 8.0, "Inglês": 6.0, "Atingiu PV": "Não" }
200 — Response (PredictionResponse)
{ "risco": 1, "risco_label": "Risco", "probabilidade_risco": 0.82, "probabilidade_sem_risco": 0.18 }
Campos do Response
risco1 = Em Risco · 0 = Sem Risco
risco_label"Risco" ou "Sem Risco"
prob_riscoProbabilidade [0–1] de defasagem
prob_sem_riscoProbabilidade [0–1] de estar OK

6. Monitoramento Contínuo

A implantação é apenas o começo. O sistema combina três camadas de observabilidade para garantir previsões confiáveis.

Data Drift

O script drift_detection.py compara a distribuição dos dados novos com a base de treino.

  • Teste estatístico por feature
  • Relatório drift_report.json
  • Alerta automático de degradação
Dashboard Streamlit

Painel visual para acompanhamento em tempo real da saúde do modelo.

  • Métricas de validação e teste
  • Feature importance ao vivo
  • Histórico de desempenho
Uptime Robot

Monitoramento externo 24/7 da disponibilidade da API em produção.

  • Ping a cada 5 minutos
  • Alertas via e-mail em caso de queda
  • 📊 Relatório público
